# Aprendizado de Máquina 2

Aulas, laboratórios e avaliações da disciplina de Aprendizado de Máquina 2 (2º semestre de 2026). O conteúdo vai de redes neurais (Perceptron e MLP) e ajuste de hiperparâmetros, passando por CNN, até redes recorrentes (RNN, LSTM e GRU). Os laboratórios usam notebooks Jupyter com os datasets Moons e Fashion-MNIST.
